# 戦国行脚 — Siv3D 縦切り完成版

Siv3D の新規プロジェクトに、このフォルダ内の **すべての `.cpp` と `.hpp`** を追加してください。
`Main.cpp` はプロジェクトの既存 `Main.cpp` と置き換えます。

## 遊び方

- 矢印キー / WASD: 主人公を移動
- Space / Enter: 町・城に入る、メニューを決定
- ↑ / ↓: メニューを選択
- Esc / 0: マップへ戻る

## 実装済み

- 四季・年齢・月の経過
- 4拠点の戦国マップ
- 町: 仕事、宿、道場
- 城: 仕官、任務
- 金、体力、武芸、名声、家臣状態
- 素材不要の和風UIと、後から画像へ差し替えられる描画分離

## 次の拡張ポイント

- `Location::draw()` を Texture 描画に置換して城・町の絵を入れる
- `Location` の派生クラスとして道場、港、寺、忍びの里を追加
- `ActionResult` を使い、商売・イベント・任務を追加
- `GameDate` を利用して季節イベント・戦国大名の行動を追加
